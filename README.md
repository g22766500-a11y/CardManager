# CardManager

## CardWheel에서 이어집니다

CardManager의 후속 개발은 **CardWheel**에서 진행합니다.
최신 소스 코드와 업데이트는 아래 저장소에서 확인해 주세요.

### 이름이 바뀐 이유

원래는 CardManager를 계속 만들려고 했습니다.
그런데 개발자가 기존 코드를 전부 날려버리는 바람에, 리팩터링할 코드 자체가 없어졌습니다. 🫠

덕분에 기술 부채는 0이 됐습니다. 소스 코드도 0이 됐지만요.

그래서 이번에는 **CardWheel**이라는 이름으로 다시 시작합니다.
카드 혜택을 놓치지 않는 앱을 만들기 전에, 일단 코드부터 놓치지 않기로 했습니다.

### [→ CardWheel 저장소로 이동](https://github.com/g22766500-a11y/CardWheel)

CardWheel은 카드 이벤트의 실적, 혜택, 주요 일정을 한곳에서 관리하는 Android 앱입니다.

이 저장소는 CardManager가 존재했다는 흔적을 남깁니다.
새로운 기능과 개선 사항은 CardWheel에 반영됩니다.
